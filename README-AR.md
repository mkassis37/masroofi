# إصلاح إصدار مصروفي

هذا الملف المضغوط **تحديث لسير عمل GitHub Actions فقط**، وليس نسخة كاملة من كود التطبيق.

## السبب
سجل التشغيل 38271620016 يثبت أن EAS نجح في بناء وتنزيل APK، لكن رفعه فشل لأن الإصدار v1.0.4 غير قابل للتعديل (immutable).

## التثبيت
1. افتح مشروع masroofi الموجود لديك محليًا.
2. انسخ الملف `.github/workflows/android-release.yml` من هذه الحزمة إلى المسار نفسه في المشروع، مع استبدال القديم.
3. ارفع التعديل إلى فرع main.
4. تأكد من وجود أسرار GitHub Actions: `EXPO_TOKEN` و `EAS_PROJECT_ID`.
5. أنشئ **وسم إصدار جديدًا** مثل `v1.0.5` يشير إلى آخر commit في main، ثم ادفعه إلى GitHub. لا تعِد استخدام `v1.0.4`.
6. راقب Actions، وبعد النجاح افتح Releases لتحميل APK.

## الضمانات والحدود
- يفحص TypeScript والاختبارات وlint قبل البناء.
- ينشر الإصدار الجديد كمسودة أولًا، ثم يرفع APK وملف SHA256، ثم ينشر الإصدار.
- يمنع إعادة الكتابة على إصدار منشور وغير قابل للتعديل.
- لم يُختبر بناء EAS أو GitHub Actions فعليًا ضمن هذه البيئة؛ يلزم تشغيله في مستودعك.
- يُستخدم ملف APK من EAS وفق إعدادات التوقيع الموجودة في حساب Expo.
